What changed from the original files:

- `Seeed_Studio_XIAO_Series.kicad_sym` holds only the `XIAO-ESP32-S3-SMD` symbol, and the file header was set to the KiCad 9 format.
- `Seeed_Studio_XIAO_Series.pretty/` holds only the `XIAO-ESP32-S3-SMD` and `XIAO-ESP32-S3-DIP` footprints, unchanged.
